SoftEther VPN - Windows Build Instructions
==========================================

The instructions that used to live in this file are obsolete. They assume
Visual Studio 2008 SP1 and the Windows SDK 6.0A, neither of which works on
a clean Windows 11 install.

For the modernized build process targeting Visual Studio 2026 and the
Windows 11 SDK, see:

    BUILD_WINDOWS.md   (in this same directory)

That document covers prerequisites, environment setup, the patches applied
to the source tree, the per-binary porting checklist, troubleshooting, and
CI automation.
